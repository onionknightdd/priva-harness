# 交互 API 参考站设计

确认范围：桌面浏览、本地预览。沿用用户提供的 [OpenAI Create Response 参考页](https://developers.openai.com/api/reference/resources/responses/methods/create?site_locale=en)的三栏文档组织方式，内容使用本项目面向平台外部客户端的共享流与 A2A 草案。当前 Chat UI 不消费该协议。

```text
+-------------------------------------------------------------------+
| Harness / Developers      API reference / Stream playground        |
|                           搜索 / Cmd K       Draft v3   明暗主题   |
+----------------+----------------------------+---------------------+
| 左侧分组导航   | 接口名称、方法与路径       | 请求 / 返回代码示例 |
| HTTP API       | 说明、请求参数、返回对象   | 场景与语言选择      |
| 共享协议       | 可展开嵌套字段             | 复制代码            |
| 指南           | 完整路径 / 类型 / 必填     | 当前页面目录        |
| 交互演示       | 默认值与字段语义           | 演示入口            |
+----------------+----------------------------+---------------------+

Stream playground
+-------------------------------------------------------------------+
| 播放 / 暂停 / 上一帧 / 下一帧 / 重置       从 seq 8 重连            |
+----------------+-------------------------+-------------------------+
| 事件时间线     | 当前帧                  | 累积结果                |
| seq 0 .. 16    | 增量 / 完整路径 / JSON  | 组件 / 完整状态 JSON    |
| 原始事件名称   | 路径 -> 实际内容        | 思考、工具、子任务、回复|
+----------------+-------------------------+-------------------------+
```

## 交互与内容

- 11 个文档页：发送消息、共享事件流、查询/列出/取消任务、标准流式发送与订阅、事件与增量操作、输出组件、断线恢复、A2A 兼容。
- 450 个字段、35 个示例；字段显示完整 Dot Notation 路径，数组与扩展 URI 键保留明确的括号表示。
- 每字段标注 A2A 标准、自定义扩展或 HTTP / SSE 标准；平台映射/约定作为可叠加标签，来源可点击查看。原始 payload 与业务 JSON 的内部字段按各自来源解释。
- 搜索覆盖页面及字段，定位时自动展开父字段；不同联合分支通过页面、section 和字段路径区分。
- 示例包含 cURL、JavaScript、Python、JSON、SSE，可切换及复制。复制失败会提供反馈。
- 17 帧合成演示涵盖思考时间 1.2 秒、工具执行、子 agent、文本追加、主任务结束后的后台输出、未知原始事件及 snapshot(8) 续传。
- 使用项目的 shadcn/ui Button、Input 基础组件，集中定义主题 token；状态反馈动效遵循 reduced motion。

## 数据流与范围

```text
协议文档 / 合成样例
      |
      v
site/src/data/reference.json + stream.json
      |
      +--> 文档字段树 / 搜索 / 示例
      |
      +--> 按 seq 应用每帧 edits（原子提交）
                    |
                    +--> 原始帧查看
                    +--> 累积组件渲染
```

站点不触发真实 Harness 或工具调用。页面中的“运行”“完成”等状态来自固定样例。

最新协议内容以 [HTTP API 参考](../api/harness-http-api-reference.md)为准；站点源码与启动命令见 [site/README.md](../site/README.md)。

## 字段来源标注

沿用已确认的三栏布局，在完整路径下补充来源与可选平台约定：

```text
contextId  string
request.message.contextId
[A2A standard] [Platform convention]
contextId <-> sessionId
```

`reference.json` 每个字段保存显式 `provenance`，引用统一的 `provenanceSources`；
它们仅为文档元数据，不进入 HTTP 请求、共享帧或组件状态。来源、约定和说明均进入
搜索与复制 Markdown；完整参考文档的下载副本同步来源说明。
